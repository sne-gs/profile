# snegs/resume

Personal resume site. The resume is served as a web page, and the PDF version is
rendered by CI on every push to `main` and deployed together with the site to
Cloudflare Pages.

## Live URLs (after deploy)

| URL                   | Content                             |
| --------------------- | ----------------------------------- |
| `/`                   | Resume (English)                    |
| `/pt-br`              | Resume (Português – Brasil)         |
| `/resume.pdf`         | Resume PDF (English)                |
| `/resume_pt-br.pdf`   | Resume PDF (Português)              |

The "Download PDF" button on each page links to the PDF in the same language.
Cloudflare Pages automatically redirects `/pt-br.html` to `/pt-br`.

## Project layout

| Path                                | Purpose                                            |
| ----------------------------------- | -------------------------------------------------- |
| `resume.html`, `resume_pt-br.html`  | Sources for the pages (rendered by the browser and by WeasyPrint) |
| `fonts/`                            | Typefaces embedded via `@font-face`                |
| `build.sh`                          | Builds the site and the PDFs into `dist/`          |
| `manifest.scm`, `.envrc`            | Guix shell for local builds (WeasyPrint, fontconfig) |
| `.forgejo/workflows/deploy.yml`     | CI: build + deploy to Cloudflare Pages             |
| `wrangler.toml`                     | Cloudflare Pages project configuration             |

The PDFs are no longer committed to the repository: they are build artifacts,
regenerated by CI on every deploy (and locally by `build.sh`).

## Build locally

```sh
guix shell        # or: direnv allow (loads manifest.scm via .envrc)
./build.sh        # produces dist/
```

Preview the built site:

```sh
npx wrangler pages dev dist     # http://localhost:8788
# or simply open dist/index.html in a browser
```

## Deploy

Automatic: every push to `main` runs the Forgejo Actions workflow, which installs
WeasyPrint, builds `dist/` and deploys it to Cloudflare Pages with wrangler.

### One-time setup checklist

1. Cloudflare: create an API token with the **Cloudflare Pages — Edit** permission
   (Dash → My Profile → API Tokens → Create Token) and note your **Account ID**
   (Dash → Workers & Pages → right sidebar).
2. Codeberg: repository **Settings → Units → enable Actions**.
3. Codeberg: repository **Settings → Actions → Secrets**, add:
   - `CLOUDFLARE_API_TOKEN`
   - `CLOUDFLARE_ACCOUNT_ID`
4. Push to `main`. The first run creates the Pages project `snegs-resume`
   (https://snegs-resume.pages.dev) automatically. If that name is taken, change
   `name` in `wrangler.toml` and in the `pages project create` step of the workflow.

A custom domain can be attached later in the Pages project settings
(Custom domains). To deploy manually at any time: `npx wrangler pages deploy`.
